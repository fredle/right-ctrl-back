# Right Ctrl Back

Turn the AI key on new laptops back into Right Ctrl, or anything else you choose.

A Windows micro app generated by app-factory. The spec is in `SPEC.md`.

## Stack (fixed - do not change)

- Rust 2024, `eframe`/`egui` 0.36 (glow), single exe, `#![windows_subsystem = "windows"]`.
- Velopack for install and self-update from GitHub Releases. Released by
  `.github/workflows/release.yml` on `v*` tags: Trusted Signing, GitHub
  Release, blob mirror, Microsoft Store submission.
- eframe 0.36's `App` trait method is `fn ui(&mut self, ui: &mut egui::Ui, frame: &mut eframe::Frame)`,
  and panels take that `Ui` (`CentralPanel::default().show(ui, ...)`).
  Side/top/bottom panels are `egui::Panel::left/right/top/bottom(id)` -
  there is no `TopBottomPanel` or `SidePanel` in 0.36.

## Factory-owned files - leave as-is

- `src/update.rs`, `src/main.rs` (only add `mod` lines),
  `.github/workflows/release.yml`, `build.rs`.
- The footer in `src/app.rs` (auto-update toggle + version) must stay.

## Rules for building the app

- Implement the spec in `src/app.rs` and new modules. Keep it small and
  dependency-light; every new crate needs a reason.
- Persist state under `settings::data_dir()` (%LOCALAPPDATA%\RightCtrlBack).
- No network calls except the update check, unless the spec requires them.
- No telemetry, no accounts, no admin rights.
- Put logic that can be tested in plain functions and cover it with
  `#[cfg(test)]` unit tests. `cargo build --release` and `cargo test` must
  pass with no warnings.
